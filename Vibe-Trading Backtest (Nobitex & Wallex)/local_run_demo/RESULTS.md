# اجرای واقعیِ موتور Vibe-Trading روی نوبیتکس (BTCIRT) — ۴ حالت پرفورمنس

## ⚠️ افشای شفاف قبل از هر چیز

این محیط sandbox که من در آن اجرا می‌شوم، سیاست شبکه‌ی سازمانی‌اش فقط به دامنه‌های مشخصی (PyPI، GitHub، npm، API آنتروپیک و ...) اجازه‌ی خروجی می‌دهد. تلاش مستقیم برای رسیدن به API نوبیتکس (`apiv2.nobitex.ir`) هم با `curl` و هم با ابزار fetch وب، هر دو با خطای `403 Forbidden` در پروکسی سازمانی رد شدند — یعنی از این محیط **امکان دریافت داده‌ی زنده‌ی نوبیتکس وجود ندارد** و من این محدودیت را دور نزدم (مثلاً از طریق پروکسی واسط عمومی).

برای اینکه با وجود این محدودیت، **کد واقعی و بدون تغییر** پکیج را اجرا کنم، کاری که کردم این بود:

1. پکیج رسمی `vibe-trading-ai` نسخه‌ی **0.1.15** را مستقیماً از PyPI نصب کردم (`pip install vibe-trading-ai`) — همان پکیجی که کاربر روی سیستم خودش نصب می‌کند.
2. فقط لایه‌ی HTTP (`requests.Session.get`) لودر نوبیتکس را موقتاً mock کردم تا به‌جای تماس با سرور واقعی، یک پاسخ JSON با **همان ساختار دقیق UDF نوبیتکس** (فیلدهای `s/t/o/h/l/c/v`) اما با **قیمت‌های تصادفیِ ساخته‌شده (synthetic)** برگرداند.
3. از آن نقطه به بعد، **هیچ خط کدی دست‌کاری نشده**: خودِ `backtest/loaders/nobitex.py` (پارس/صفحه‌بندی/اعتبارسنجی OHLC واقعی)، خودِ `backtest/engines/crypto.py` (CryptoEngine واقعی)، و خودِ `backtest/metrics.py` (فرمول‌های Sharpe/Sortino/Calmar/MDD واقعی) روی این داده اجرا شدند — دقیقاً همان مسیر کدی که مستند [`../ALGORITHM.md`](../ALGORITHM.md) توضیح داده.

**نتیجه یعنی چه؟** اعداد پرفورمنسی که پایین آمده، **بازتاب رفتار واقعی موتور بک‌تست Vibe-Trading** هستند (سایزینگ سفارش، اسلیپیج، کارمزد Maker/Taker، محاسبه‌ی equity، همه‌ی فرمول‌های متریک) — ولی چون قیمت‌های ورودی BTCIRT واقعی بازار نیستند بلکه یک random-walk شبیه‌سازی‌شده‌اند، **این اعداد را نباید به‌عنوان پیش‌بینی سود واقعی در بازار نوبیتکس تفسیر کرد**. برای گرفتن نتیجه‌ی واقعی، باید همین را روی ماشینی که به اینترنت آزاد دسترسی دارد اجرا کنید (دستور دقیق پایین صفحه آمده).

## چه چیزی واقعی و چه چیزی شبیه‌سازی‌شده بود؟

| بخش | واقعی؟ |
|---|---|
| نسخه‌ی پکیج (`vibe-trading-ai==0.1.15`) | ✅ نصب واقعی از PyPI |
| کد `loaders/nobitex.py` (پارس/صفحه‌بندی/validate_ohlc) | ✅ بدون تغییر |
| کد `engines/base.py` + `engines/crypto.py` (سایزینگ، اسلیپیج، کارمزد، PnL) | ✅ بدون تغییر |
| کد `metrics.py` (Sharpe/Sortino/Calmar/MDD/IR/Turnover) | ✅ بدون تغییر |
| مسیر HTTP واقعی به `apiv2.nobitex.ir` | ❌ مسدود توسط سیاست شبکه‌ی sandbox؛ mock شد |
| قیمت‌های BTCIRT ورودی | ❌ synthetic (random walk با seed ثابت)، نه قیمت واقعی بازار |
| استراتژی‌ها (سیگنال‌ها) | نوشته‌ی من (به‌جای ایجنت LLM)، تا نیازی به API Key نباشد |

## پیکربندی مشترک اجراها

```json
{
  "source": "nobitex",
  "codes": ["BTCIRT"],
  "start_date": "2024-05-11",
  "end_date": "2025-09-13",
  "interval": "1D",
  "initial_cash": 100000000
}
```
(۴۹۰ کندل روزانه — محدود به همین بازه چون endpoint واقعی نوبیتکس هر صفحه حداکثر ۵۰۰ کندل می‌دهد و mock هم همین رفتار را عیناً شبیه‌سازی کرد.)

| حالت | بازده کل | بازده سالانه | Sharpe | Sortino | Calmar | حداکثر افت | نرخ برد | تعداد معامله | میانگین Turnover |

(بنچمارک داخلی هر ۴ اجرا — میانگین بازده خودِ نماد — یکسان است: بازده کل = ۳۲.۶۶٪)

فایل‌های خام هر اجرا (خروجی مستقیم موتور، بدون دست‌کاری) در [`results/`](./results) قرار دارند: `config.json`، `metrics.csv` (همه‌ی ۳۵ شاخص، نه فقط جدول بالا)، `equity.csv` (منحنی equity کندل‌به‌کندل)، `trades.csv` (لیست معاملات) و `run_card.md`.

## جمع‌بندی تفسیری (فقط برای همین داده‌ی synthetic؛ تعمیم به بازار واقعی ندهید)

- استراتژی‌های **روندی/کراس میانگین متحرک** (MA 20/50 و MA 10/30) روی این سری‌ی synthetic (که حرکت میانگین‌گریز/نویزی دارد نه روند قوی) عملکرد منفی داشتند — رفتار طبیعی MA-crossover وقتی بازار trending نیست (whipsaw).
- استراتژی **RSI mean-reversion** روی همین داده بهترین عملکرد را داشت چون سری قیمت به سمت میانگین برمی‌گشت — دقیقاً پیش‌فرضی که RSI mean-reversion رویش طراحی شده.
- **این رتبه‌بندی صرفاً خاصیت آماری داده‌ی تصادفی تولیدشده است، نه شواهدی درباره‌ی رفتار واقعی بازار نوبیتکس.**

## چطور خودتان همین را با داده‌ی واقعی نوبیتکس اجرا کنید

روی ماشینی که به اینترنت آزاد دسترسی دارد (نه این sandbox):

```bash
pip install vibe-trading-ai
mkdir -p ~/.vibe-trading/runs/my_nobitex_test/code
cp signal_engines/nobitex_rsi_meanrev.py ~/.vibe-trading/runs/my_nobitex_test/code/signal_engine.py
cat > ~/.vibe-trading/runs/my_nobitex_test/config.json <<'JSON'
{
  "source": "nobitex",
  "codes": ["BTCIRT"],
  "start_date": "2024-05-11",
  "end_date": "2025-09-13",
  "interval": "1D",
  "initial_cash": 100000000
}
JSON
python -m backtest.runner ~/.vibe-trading/runs/my_nobitex_test
cat ~/.vibe-trading/runs/my_nobitex_test/artifacts/metrics.csv
```
یا ساده‌تر، از طریق ایجنت گفتگویی (نیاز به کلید LLM دارد):

```bash
vibe-trading run -p "با استفاده از منبع نوبیتکس، استراتژی RSI(14) mean-reversion را روی BTCIRT از 2024-05-11 تا 2025-09-13 بک‌تست کن"
```

فایل‌های `signal_engines/*.py` و `mock_nobitex_transport.py` و `drive.py` در همین پوشه برای بازتولید کامل این آزمایش (یا اجرای مشابه با داده‌ی واقعی، فقط با حذف mock) نگه‌داری شده‌اند.
