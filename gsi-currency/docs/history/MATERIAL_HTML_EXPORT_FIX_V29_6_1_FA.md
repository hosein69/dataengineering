# GSI V29.6.1 — اصلاح همسانی متریال بین دید تأمین و HTML

## مسئله
متریال در تب «دید تأمین / متریال محور» Streamlit قابل مشاهده بود اما در HTML ساخته‌شده از Report Composer الزاماً حضور نداشت. علت این بود که Preview از `build_material_view()` استفاده می‌کرد، در حالی که HTML فقط DataFrame پایه و فیلدهای ذخیره‌شده Template/Tab را می‌گرفت.

## اصلاح
- HTML اکنون بخش ثابت «دید تأمین — متریال محور» را مستقیماً از همان `build_material_view()` می‌سازد.
- اگر `KEY_MATERIAL` در داده مقدار واقعی داشته باشد، هویت متریال در جدول اصلی HTML حتی برای طرح‌های ذخیره‌شده قدیمی حذف نمی‌شود.
- این اصلاح منطق Grain و تجمیع مبالغ را تغییر نمی‌دهد و فقط شکاف Preview/Export را می‌بندد.
