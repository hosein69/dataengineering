# فونت‌ها: اول راوی، اگر نبود ایران‌سنس

فایل‌های این پوشه را مالک پروژه از نسخه دارای مجوز سازمان فرستاده است. راوی و ایران‌سنس
هر دو تجاری‌اند (fontiran.com)؛ فایل‌ها را بیرون از سازمان منتشر نکنید.

| فایل | وزن | کاربرد |
|---|---|---|
| `RaviFaNum-Regular.woff` | معمولی (۴۰۰)، ارقام فارسی | متن معمولی؛ ارقام لاتین این وزن از ایران‌سنس می‌آید |
| `Ravi-SemiBold.woff2` | نیم‌ضخیم (۶۰۰) | برچسب‌ها و عنوان‌های نیم‌ضخیم |
| `Ravi-Bold.woff2` | ضخیم (۷۰۰) | عنوان‌ها، تب‌ها و عددهای شاخص |
| `Ravi-SemiBold.ttf` | نیم‌ضخیم (۶۰۰) | نمودارهای ایمیل |
| `Ravi-ExtraBlack.woff2` و `.woff` | ۹۵۰ | جاسازی نمی‌شود؛ عنوان‌های وزن ۸۰۰ را بیش از حد سنگین می‌کرد |
| `IRANSans-web.woff` | معمولی (۴۰۰) | ارقام لاتین متن معمولی، و هر جا فایل راوی نباشد |

* **افزودن یا عوض کردن فایل:** هر فایلی که نامش با `Ravi` یا `IRANSans` شروع شود و پسوند
  `woff2`، `woff`، `ttf` یا `otf` داشته باشد پذیرفته است. وزن از نام فایل خوانده می‌شود
  (Regular، Medium، SemiBold، Bold، …). برای هر وزن، نسخه ارقام لاتین بر FaNum مقدم است.
  بعد Studio را دوباره اجرا کنید.
* **ارقام راوی در متن معمولی:** فایل `Ravi-Regular` با ارقام لاتین را اضافه کنید؛ خودکار
  جای نسخه FaNum را می‌گیرد.
* **جاسازی:** از همین پوشه، فونت داخل Studio و داخل HTMLهای ارسالی (گزارش چرخه ارز،
  گزارش‌ساز، تابلوی بحرانی) می‌نشیند تا گیرنده بدون نصب فونت همان صفحه را ببیند.
  اگر مجوز شما جاسازی در فایل ارسالی را پوشش نمی‌دهد: `GSI_EMBED_FONTS=0`.
* **پوشه دیگر:** مسیرش را در `GSI_FONT_DIR` بگذارید (در `OPS\GSI_ENV.cmd`).
* **بدنه ایمیل و Excel** فونت را همراه نمی‌برند و نام `IRANSans Light` را دارند؛ این فونت
  باید روی رایانه گیرنده نصب باشد.
* فونت نصب‌شده سیستم هرگز در فایل ارسالی جاسازی نمی‌شود.
* وضعیت فونت در نوار کناری Studio نوشته می‌شود.
