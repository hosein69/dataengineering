# HRPerf 3.2.0 — نظام طراحی «آکوا»، مشترک با پکیج زنجیره تأمین

هر خروجی این پکیج پالت خودش را داشت: اکسل یک آبی، HTML آبی دیگر، نقشهٔ
سیال یک طیف کاملاً متفاوت — و پکیج زنجیره تأمین سبز. چهار فایل کنار هم،
چهار محصول به‌نظر می‌رسیدند.

حالا `hrperf/report/aqua.py` تنها منبع رنگ است. نسخهٔ یکسان همین فایل در
`aibl/report/aqua.py` هست — عمداً کپی، تا هیچ پکیجی به دیگری وابسته نشود
و هرکدام مستقل نصب شود.

| سفید روی دکمهٔ برند `#00A693` | ۳٫۰۵:۱ — زیر حد متن | دکمه `#007D6E` (۵٫۰۵:۱) |

متن بدنه روی پس‌زمینه ۱۱٫۷:۱، عنوان روشن روی سبز تیره ۶٫۳۱:۱، مفرغی روی
سبز روشن ۴٫۸۴:۱.

## دو چیزی که پالت اصلی نداشت

**طیف دسته‌ای نمودار.** پالت اصلی یک خانوادهٔ رنگی است؛ سه سبزش در نمودار
از هم قابل تشخیص نیستند (ΔE دید عادی ۸٫۱ — زیر کف ۱۵). طیف تازه لنگرش
همان آکوای برند است ولی هیوها پخش‌اند:

```
#008E82  #C4761A  #2F74D0  #B0357A  #5E8C1B  #7A5AD6  #B03A2E  #1478A0
```

**حالت تاریک.** سطوح تاریک از خانوادهٔ آکوا مشتق شده‌اند، نه خاکستری
خنثی. هر دو طیف روی **سطح واقعی خودشان** سنجیده شده‌اند:

```
روشن  (سطح #E1F2E9): CVD ΔE ۱۲٫۰ · دید عادی ΔE ۲۱٫۷ — هر شش بررسی PASS
تاریک (سطح #0C1F1A): CVD ΔE ۱۰٫۹ · دید عادی ΔE ۲۲٫۰ — هر شش بررسی PASS
```

## کجاها عوض شد

| فایل | چه چیزی |
|---|---|
| `report/aqua.py` | **تازه** — توکن‌ها، طیف‌ها، رنگ وضعیت، تولید CSS و تم اکسل |
| `report/theme.py` | دیگر رنگی تعریف نمی‌کند؛ نام‌های قدیمی را به آکوا وصل می‌کند |
| `report/excel.py` | هدر، بردر، سطر یک‌درمیان با پس‌زمینهٔ همان سیستم |
| `report/html.py` | سطح، کارت، هاور جدول، ورودی‌ها |
| `report/dynamic.py` | طیف و طبقه‌های امتیاز |
| `report/fluid.py` | متغیرهای CSS هر دو تم مستقیم از `aqua.css_vars()` |
| `report/email.py` | هدر، کارت KPI، بردر و متن |

طبقه‌های امتیاز حالا در همه‌جا یکی است: جدول، نمودار، اکسل و ایمیل یک
مرز و یک رنگ دارند.

## تست

**۳۰۱ تست، ۰ ناموفق.** دو تستی که پالت قدیمی را قفل کرده بودند به آکوا
به‌روز شدند و حالا هر دو تم را می‌سنجند.

یک باگ واقعی هم همین کار پیدا کرد: `report/email.py` پس از جایگزینی
رنگ‌ها، `SyntaxError` می‌داد — کوتیشن تودرتو در f-string. تست‌های
سرتاسری همان لحظه گرفتندش.
