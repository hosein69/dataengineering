# HRPerf — داشبورد عملکرد منابع انسانی (نسخه ۱٫۰٫۰)

سنجش عملکرد بر پایه **علیت**، نه صرفاً همبستگی. مدل دو سطحی است، وزن‌ها
در داشبورد زنده تغییر می‌کنند، و خروجی هم پایگاه داده است هم Excel و
HTML و PDF و بسته ایمیل.

> ارزیابی کامل پکیج قبلی و ده ایراد آن در `ARZYABI_PACKAGE_GHABLI.md`.

```bash
pip install -r requirements.txt
python -m hrperf.cli demo            # اجرای نمونه بدون شبکه
python -m hrperf.cli run             # اجرا روی input_files
python app/run_dashboard.py          # داشبورد
python run_all_tests.py              # ۷۲ تست
```

## ۱. الگوریتم

```
سورس‌ها ──► خط لوله ──► شاخص ──► کلاستر ──► عملکرد
                         │         │          │
                    (وزن آیتم) (وزن کلاستر)  │
                                              ▼
                                      تعدیل علّی ──► امتیاز منصفانه
```

### ۱٫۱ ورود مستقیم و غیرمستقیم

هر شاخص در `model.yaml` اعلام می‌کند چگونه وارد کلاستر می‌شود:

- `entry: direct` — مقدار مستقیماً از سورس می‌آید.
- `entry: derived` — با فرمولی از شاخص‌های دیگر ساخته می‌شود
  (`formula:`)، مثل `A/E` و «سختی مورد انتظار».

### ۱٫۲ گروه همتا — چه کسی با چه کسی مقایسه می‌شود

مقایسه فقط درون `(مدیریت، اداره، نوع کار)` انجام می‌شود. اگر گروه از
حد نصاب (پیش‌فرض ۴ نفر) کوچک‌تر باشد، یک پله بالا می‌رود و **همین صعود
در خروجی ثبت می‌شود**، تا خواننده بداند مقایسه در چه سطحی بوده است.

### ۱٫۳ انقباض — چرا نمونه کوچک رتبه اول نمی‌شود

واریانس مقدار هر فرد دو بخش دارد: نویز نمونه‌گیری و تفاوت واقعی.

```
Var(xᵢ) ≈ σ²/nᵢ + τ²      ⇒   k = σ² / τ²
x̂ = (nᵢ·xᵢ + k·μ) / (nᵢ + k)
```

`k` با رگرسیون انحراف مجذور روی `1/nᵢ` از خود داده برآورد می‌شود.
اثرش روی داده واقعی:

| مقدار خام | n | بدون انقباض | با انقباض |
|---|---|---|---|
| ۱٫۰۰ | ۲ | **۷۹٫۵ (رتبه ۱)** | ۵۳٫۷ |
| ۰٫۹۸ | ۱۲۰ | ۶۴٫۶ | **۷۳٫۱ (رتبه ۱)** |

### ۱٫۴ امتیاز مطلق، نه رتبه‌ای

امتیاز نسبت به توزیع مرجع با میانه و MAD ساخته می‌شود و با
`50 + 45·tanh(z/2)` به بازه ۵..۹۵ نگاشت می‌گردد. اگر کل تیم بهتر شود،
امتیاز همه بالا می‌رود — چیزی که در رتبه درصدی ممکن نیست.

### ۱٫۵ تجمیع دو سطحی

```
cluster_score_c = Σ w_item_i · score_i        (نرمال روی آیتم‌های موجود)
performance     = Σ w_cluster_c · cluster_score_c
effective_weight_i = w_item_i × w_cluster_c
```

نبودِ یک شاخص، امتیاز را بی‌صدا پایین نمی‌آورد؛ در عوض **پوشش** پایین
گزارش می‌شود. `اطمینان = √(پوشش × شواهد)`.

### ۱٫۶ لایه علّی

DAG صریح اعلام می‌شود، مجموعه تعدیل با **معیار درِ پشتی** از همان DAG
استخراج می‌گردد، و اثر با باقی‌مانده‌گیری (Frisch–Waugh–Lovell) برآورد
می‌شود. خروجی، همبستگی خام را کنار اثر تعدیل‌شده می‌گذارد:

| از → به | همبستگی خام | اثر تعدیل‌شده | نتیجه |
|---|---|---|---|
| سختی → سرعت | −۰٫۵۴ | **۰٫۰۱** | همبستگی کاملاً مخدوش بود |
| سرعت → کیفیت | ۰٫۷۴ | ۰٫۲۶ | بخش بزرگی مخدوش بود |

**امتیاز منصفانه** = عملکرد واقعی منهای آنچه از شرایط کار (حجم، سختی،
تخصیص، سابقه) انتظار می‌رفت — تعمیم چندمتغیرهٔ A/E.

> ⚠️ با داده مشاهده‌ای علیت **اثبات** نمی‌شود. این اعداد «اثر تعدیل‌شده
> تحت فرض‌های DAG اعلام‌شده» هستند. ستون E-value می‌گوید یک مخدوش‌کننده
> اندازه‌گیری‌نشده چقدر باید قوی باشد تا نتیجه را برگرداند.

## ۲. وزن‌های پیشنهادی و مبنایشان

| کلاستر | وزن | چرا |
|---|---|---|
| دقت و کیفیت | ۴۰٪ | خطای سند به توقف خط و جریمه ارزی تبدیل می‌شود |
| سرعت و پاسخ‌گویی | ۲۲٪ | همیشه جفت با کیفیت (اصل DORA) |
| بازدهی و تکمیل | ۱۸٪ | بستن پرونده و باز نماندن کار |
| هزینه دوباره‌کاری | ۱۵٪ | اثر مالی خطا، بدون دوباره‌شماری با کیفیت |
| حجم و پیچیدگی | ۵٪ | عمداً کم — حجم شرایط کار است نه عملکرد |
| مسئولیت مالی | ۰٪ | تخصیص است نه عملکرد؛ فقط زمینه |

مبنا: **SPACE** (GitHub/Microsoft Research 2021) — فعالیت به‌تنهایی
معیار عملکرد نیست؛ **DORA** — سرعت و پایداری جفت؛ **Balanced Scorecard**
(Kaplan & Norton) — توازن کیفیت/سرعت/هزینه؛ **Six Sigma FPY** — کیفیت
بار اول سنگین‌ترین وزن.

هر دو سطح در داشبورد قابل تغییرند و پس از هر تغییر بازنرمال می‌شوند.

### فهرست گیرندگان ایمیل — پیکربندی محرمانه

نشانی کارکنان داده شخصی است و در سورس نگه‌داری نمی‌شود:

```
HRP_EMAIL_TO="a@example.invalid;b@example.invalid"
HRP_RECIPIENTS_FILE=/secure/recipients.yaml
$HRP_HOME/recipients.yaml
```

بدون پیکربندی، ساخت گزارش کار می‌کند ولی **ارسال با خطای صریح متوقف
می‌شود**.
