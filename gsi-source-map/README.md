## اجرا

```bash
pip install pandas openpyxl pyyaml
export GSI_DATA_ROOT=/path/to/data
python tool/gsi_source_profiler.py --config tool/gsi_sources.yaml --output gsi_evidence_pack
```

کد خروج `0` یعنی همه منابع پروفایل شدند؛ `2` یعنی pack ناقص است. تست‌ها: `python -m pytest -q tool/test_profiler.py`.

برای بازتحلیل یک pack موجود بدون خواندن دوباره فایل‌ها:

```bash
python analysis/reanalyse_real_evidence.py --evidence evidence.txt --output analysis_out
```

## ⚠️ حفاظت داده

`evidence.txt` حاوی **۱٬۰۸۹ ردیف نمونه واقعی** است: نام مشتری، کد ثبت سفارش، نام تأمین‌کننده، شعبه بانک، مبالغ، و ستون‌های نام کارشناس در ۱۱ فریم.

مخزن `hosein69/dataengineering` **عمومی** است، بنابراین:

- `evidence.txt` **push نشده** و در `.gitignore` قرار گرفته است؛
- فقط تحلیل مشتق‌شده در سطح schema منتشر شده — نام ستون، نقش، شمارش، نسبت؛
- همین بسته هم فقط برای شماست و نباید در مخزن عمومی قرار بگیرد.

اگر می‌خواهید pack واقعی جایی نگهداری شود، یک مخزن **خصوصی** جدا لازم است.
