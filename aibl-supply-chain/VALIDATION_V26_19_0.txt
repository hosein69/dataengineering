DEBUG — DEFECTS FIXED AND HOW EACH WAS MEASURED
1) RTL chart labels drawn underneath the bars.
   In a dir="rtl" document SVG text-anchor="end" resolves to the LOGICAL end,
   which for RTL text is the left side. Measured in Chromium at anchor x=240:
     text-anchor="end"                        -> text box [272 .. 374]  (on the bar)
     direction:ltr; unicode-bidi:plaintext    -> text box [170 .. 272]  (correct)
   Fix: one CSS rule on all SVG text. unicode-bidi:plaintext takes direction
   from each label's own first strong character, so Persian activity names and
   Latin material codes both render correctly.
2) Outlook (-2147221008) "CoInitialize has not been called", Studio send path only.
   Streamlit runs each interaction on a fresh ScriptRunner thread; win32com
   requires CoInitialize on that thread. Both call sites now use one
   _outlook_session() context manager; CoUninitialize runs on every exit path
   including the error path.
3) Email KPI cards overflowed: six cards at width:20% in one row = 120%.
   Now max 3 per row, width computed from count.
4) Missing glyphs in email chart PNGs. Measured on matplotlib 3.11:
     font.family="sans-serif" + font.sans-serif=[X,"DejaVu Sans"] -> 123 warnings
     font.family=[X,"DejaVu Sans"]                                -> 0 warnings
   Per-glyph fallback only engages for an explicit list of real font names.
5) KPI card accent rule used #F39C12 at 1.9:1 on white. Now the measured ink.
