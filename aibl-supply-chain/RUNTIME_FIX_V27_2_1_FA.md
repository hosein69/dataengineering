# اصلاحیه ۲۷٫۲٫۱

## نصب کتابخانه در Python صحیح

خطای ModuleNotFoundError نشان می‌دهد cryptography در مفسری که Streamlit را اجرا می‌کند نصب نشده است. این وابستگی از قبل در requirements.txt وجود داشت، ولی نصب‌شدن آن در محیط سازمان از اینجا قابل تأیید نبود.

برای محیط Python 3.13 گزارش‌شده، در PowerShell:

```powershell
py -3.13 -m pip install "cryptography>=42.0"
py -3.13 -c "import sys, cryptography; print(sys.executable); print(cryptography.__version__)"
py -3.13 -m streamlit run app/studio.py
```

اگر از محیط مجازی استفاده می‌کنید، مسیر python.exe همان محیط را به‌جای `py -3.13` قرار دهید. در شبکه بدون دسترسی به مخزن بسته‌ها، wheelهای سازگار با Python و Windows مقصد و وابستگی‌های آنها باید از مسیر مجاز سازمان نصب شوند.

## تغییرات کد

- قفل تنظیمات مرکز مخاطبان اکنون ماژول مستقل استاندارد پایتون است. ساخت کلاستر، ویرایش مخاطبان، نگاشت منبع و ذخیره تنظیمات دیگر cryptography را هنگام import بارگذاری نمی‌کنند.
- عملیات رمزگذاری همچنان به cryptography نیاز دارد؛ رمزگذاری حذف یا با ذخیره بدون رمز جایگزین نشده است. هنگام ساخت گزارش از Snapshot یا ذخیره آن، نبود کتابخانه پیام نصب همراه مسیر دقیق Python تولید می‌کند.
- قرارداد موتور گلوگاه «میانه روز» است. دو رابط قدیمی به «میانگین روز» وابسته بودند. اکنون شاخص موجود با عنوان واقعی آن انتخاب می‌شود؛ داده قدیمی میانگین هم پشتیبانی می‌شود، بدون تغییر نام آن به میانه.
- مقدار نامعتبر، نامتناهی و منفی در مدت گذار رسم نمی‌شود؛ صفر واقعی باقی می‌ماند. نبود ستون، نمودار را متوقف می‌کند ولی باعث KeyError نمی‌شود.
- دسترسی SEQUENTIAL[6] خارج از محدوده پالت با آخرین رنگ معتبر جایگزین شد.
- پیام مقاومت، فیلتر خالی، نبود ستون، طبقه UNKNOWN و NO_CONSUMPTION را توضیح می‌دهد. صفر جای مقدار نامعلوم قرار نمی‌گیرد. مقادیر نامتناهی از نمودار حذف می‌شوند.

## درباره مقاومت

بدون فایل‌های Excel و خروجی واقعی شما نمی‌توان نتیجه گرفت نبود مقاومت یک خطای محاسباتی است. موتور قبلی برای بعضی ورودی‌های ناقص یا بدون مصرف مثبت عمداً مقدار قابل رسم نمی‌دهد. این اصلاحیه پیام تشخیص را بهتر می‌کند؛ فرمول، ETL و مقدار مقاومت را حدسی تغییر نمی‌دهد. برای بررسی علت باقی‌مانده، ردیف نمونه متریال، موجودی قابل مصرف، نیاز روزانه، کد طبقه بحرانی و مقدار مقاومت از جدول اتاق کنترل لازم است.

## به‌روزرسانی

Streamlit را ببندید؛ کد این پکیج را در پوشه تازه استخراج و با تنظیمات محیط قبلی اجرا کنید. پوشه شبکه، کلید رمزگذاری و فایل‌های شخصی قبلی را نگه دارید. از کلید جدید استفاده نکنید. مسیرهای مرکز کلاستر و قابلیت‌های نسخه ۲۷٫۲ حفظ شده‌اند.

آزمون مخصوص نبود cryptography در یک subprocess که عمداً import آن را مسدود می‌کند، ذخیره تنظیمات را تأیید کرده و مانع ادامه عملیات رمزگذاری بدون کتابخانه می‌شود. آزمون‌های قرارداد نمودار، مقدار نامعتبر، قالب قدیمی و پیام مقاومت اضافه شده‌اند. اجرای گرافیکی Streamlit و Outlook روی Windows شما همچنان آزمون محیط مقصد است.

## نتیجه واقعی آزمون‌ها

هفت آزمون تخصصی اصلاحیه موفق شدند. اجرای یکپارچه ۷۹۸ موفق و یک شکست در آزمون قدیمی افزودن/حذف پویای مرحله داشت (تعداد مرحله ۱۷/۱۸ بین دو subprocess متفاوت شد). اجرای جداگانه همان مجموعه معماری ۴۲ موفق داشت. بنابراین برای این انتشار ادعای «همه تست‌ها سبز» نداریم؛ ناپایداری آزمون کشف مرحله در اجرای یکپارچه نیازمند بررسی بیشتر است. فایل آزمایشی s95_demo_feature.py خروجی این تست است و از بسته انتشار حذف شده؛ منطق مرحله‌های عملیاتی تغییر نکرده است.
