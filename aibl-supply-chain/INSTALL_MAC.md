# اجرا روی مک — راهنمای دقیق

این سند فقط تفاوت‌های مک را می‌گوید. منطق کد، خروجی‌ها و «نظام طراحی
البرز» روی هر دو سیستم‌عامل یکی است؛ آنچه فرق می‌کند سه چیز است:
**مسیر داده**، **ارسال ایمیل** و **فونت**.

---

## ۱. اجرا

```bash
unzip AIBL_V26_20_0.zip -d ~/AIBL
cd ~/AIBL
chmod +x run_mac.command      # اگر Finder اجازهٔ اجرا نداد
./run_mac.command
```

یا در Finder روی `run_mac.command` دوبار کلیک کنید. اگر مک گفت «از
توسعه‌دهندهٔ شناخته‌شده نیست»: راست‌کلیک → Open → Open.

اسکریپت خودش `.venv` می‌سازد، وابستگی‌ها را نصب می‌کند و مرورگر را باز
می‌کند. بار اول یکی دو دقیقه طول می‌کشد.

> **پایتون ۳٫۱۱ به بالا لازم است.** پایتونی که همراه مک می‌آید ۳٫۹ است و
> کافی نیست. `brew install python` (فرمول Homebrew آخرین نسخه را می‌آورد) یا نصب از python.org.

## ۲. مسیر داده

روی ویندوز، سورس‌ها از مسیر UNC خوانده می‌شدند:

```
\\ikco.com\data-share\Global Sourcing\...
```

روی مک چنین مسیری وجود ندارد. اشتراک را در Finder سوار کنید
(`Go → Connect to Server…` و بعد `smb://ikco.com/data-share`) — مک آن را
زیر `/Volumes` می‌گذارد. پیش‌فرض ما:

```
/Volumes/data-share/Global Sourcing
```

اگر نام نقطهٔ اتصال شما فرق دارد، پیش از اجرا:

```bash
export AIBL_NET="/Volumes/<نام واقعی>/Global Sourcing"
```

همهٔ هفت مسیر سورس از همین یکی ساخته می‌شوند. هر کدام را هم می‌شود
جداگانه با `AIBL_FOREIGN`، `AIBL_BLS`، `AIBL_HR` و… جابه‌جا کرد.

خروجی و لاگ روی مک زیر `~/.aibl` می‌نشینند (نه روی اشتراک). با
`AIBL_HOME` عوض می‌شود.

## ۳. ارسال ایمیل — این یکی واقعاً فرق دارد

«ارسال با یک کلیک» روی ویندوز از **COM اتلوک** می‌آمد. اتلوک مک چنین
رابطی ندارد و «اتلوک جدید» AppleScript قدیمی را هم برداشته. پس روی مک:

| کار | ویندوز | مک |
|---|---|---|
| ساخت پیوست‌ها | ✅ | ✅ |
| متن HTML گزارش در بدنهٔ ایمیل | ✅ | ✅ |
| انتخاب گیرنده از سورس HR | ✅ | ✅ |
| باز شدن پیام در کلاینت با پیوست‌ها | ✅ | ✅ |
| **فرستادن بدون دخالت کاربر** | ✅ | ❌ |

روی مک دکمهٔ اصلی **«باز کردن در کلاینت ایمیل»** است، نه «ارسال» —
عمداً. پلتفرم پیام کامل (بدنهٔ HTML + همهٔ پیوست‌ها) را می‌سازد و در
اتلوک یا Mail باز می‌کند؛ فرستادنش یک کلیک خودتان است. دکمه‌ای به نام
«ارسال» که فقط پنجره باز کند، همان اشتباهی است که یک بار روی ویندوز
اتفاق افتاد (ذخیره به‌جای ارسال) و نباید تکرار شود.

پیام‌های ساخته‌شده موقتاً در `~/.aibl/outbox` می‌نشینند. آن پوشه `700`
است، هر پرونده `600`، و هرچه از **۷ روز** گذشته باشد خودکار پاک می‌شود —
فهرست نشانی‌ها روی دیسک تلنبار نمی‌شود. نام پرونده هیچ نشانی‌ای ندارد.

## ۴. فونت

ایران‌سنس را نصب کنید (Font Book → فایل‌های `.ttf` را بکشید تویش).
`local()`های داخل CSS نام‌های ویندوزی **و** نام‌های PostScript مک را
پوشش می‌دهند.

اگر ایران‌سنس نبود، زنجیره به ترتیب می‌رود سراغ Vazirmatn، بعد
**SF Arabic** (روی macOS 13 به بالا هست و فارسیِ تمیزی می‌دهد)، بعد
Tahoma و Geeza Pro. یعنی رابط بدون ایران‌سنس هم خوانا می‌ماند، فقط
هویت قلمش عوض می‌شود.

---

## ۵. تست

```bash
.venv/bin/python run_all_tests.py
```

تست‌های وابسته به اتلوکِ ویندوز خودشان روی مک رد می‌شوند (skip)؛ بقیه
باید سبز باشند.
