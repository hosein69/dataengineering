# اصلاح runner آفلاین 2026-09-24

این hotfix فقط تجربه و قابلیت مشاهده اجرای Diagnostic را اصلاح می‌کند و منطق کسب‌وکار GSI یا oracleهای تست را تغییر نمی‌دهد.

- CMD از همان لحظه شروع مسیر پکیج/داده و Python را نمایش می‌دهد.
- اگر `--data-dir` داده نشود، پوشه ریشه پکیج به‌عنوان مسیر داده آفلاین استفاده می‌شود.
- هر مرحله START/DONE دارد و مراحل طولانی هر 10 ثانیه heartbeat `RUNNING` چاپ می‌کنند.
- خروجی تفصیلی child processها همچنان در log ذخیره می‌شود تا console overload نشود.
- پنجره CMD در پایان با `pause` باز می‌ماند.
- Exit code 2 به معنی `Gate HOLD` و یافتن issue است، نه crash runner.
- نبود Python به‌صورت پیام FATAL قابل مشاهده گزارش می‌شود.
