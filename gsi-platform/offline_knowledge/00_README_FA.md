# بسته دانش آفلاین GSI

این پوشه برای اجرای بدون اینترنت ساخته شده است. محتوای آن سه نوع منبع را از هم جدا می‌کند:

1. **قواعد قطعی پروژه / قرارداد کسب‌وکار**: تعاریفی که کاربر و قراردادهای پروژه صریحاً تعیین کرده‌اند.
2. **شواهد داده و Source Authority**: از `evidence.txt` و گزارش‌های ممیزی/پروفایل منابع؛ این‌ها اثبات حقوقی نیستند.
3. **دانش بیرونی مشاهده‌شده**: خلاصه محافظه‌کارانه از منابع رسمی/عمومی که در بررسی وب مشاهده شده‌اند. هر قاعده حقوقی فقط در حد منبع ثبت‌شده قابل اتکاست و برای تصمیم حقوقی جاری باید نسخه معتبر همان تاریخ بررسی شود.

تست‌های آفلاین برای جلوگیری از خطاهای الگوریتمی از این دانش به‌عنوان **guardrail** استفاده می‌کنند؛ آن‌ها نرخ، مهلت، مجازات یا حکم حقوقی جدید اختراع نمی‌کنند.
