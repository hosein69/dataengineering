# GSI Build 29.6.10 — گزارش دیباگ فول‌استک

تاریخ اعتبارسنجی: 2026-09-21. مبنا: بسته دریافتی 29.6.8 و اصلاح مرز سورس‌ها در 29.6.9.
این بسته اصلاح کد و شواهد بازتولیدپذیر ارائه می‌کند؛ نتیجه اجرای داده واقعی سازمان هنوز مشاهده نشده است.

## اصلاحات

- مسیر واقعی `app/dashboard.py` فراخوانی `build_dynamic_html` داشت ولی import آن موجود نبود؛ اضافه شد. Build در Sidebar نمایش داده می‌شود.
- در دید تأمین متریال‌محور، کارشناسان و NTSW فقط «هشدار کارشناسان»، «کامنت کارشناسان»، «هشدار NTSW» و «کامنت NTSW» می‌دهند. هویت و مرحله از رابطه مستقل قابل اتکا می‌آیند؛ رابطه نامعتبر، وضعیت نامشخص می‌دهد. ردیف‌های فاقد هویت معتبر در بخش هشدار باقی می‌مانند.
- موجودی و مقاومت معتبر Oracle دوباره در دید متریال استفاده می‌شود؛ موجودی ادعایی کارشناس آن را تغییر نمی‌دهد. تاریخ مرجع گزارش در محاسبه مرحله/سن اعمال می‌شود.
- داده‌های مکمل فرآیندی/مالی در Dashboard، موتور HTML و Report Builder با محدوده انتخابی محدود می‌شوند. شناسه پرونده با شماره ثبت سفارش اشتباهاً تطبیق داده نمی‌شود. نبود ستون لازم برای محدوده، کل داده را باز نمی‌کند. محدودیت ستون‌های مجاز به نمای خودکار هم اعمال می‌شود.
- Search روی همه ردیف‌ها انجام می‌شود؛ محدودیت نمایش فقط جدول/کارت را کوتاه می‌کند. Excel، شمارنده، نمودار و جمع‌ها از تمام نتایج فیلترشده استفاده می‌کنند. جست‌وجوی ارقام فارسی پشتیبانی می‌شود.
- شناسه‌های تجاری بلند در Excel به صورت متن صادر می‌شوند. متن کامنت نمی‌تواند اسکریپت اجرا کند. حرکت کیبورد در تب‌های RTL و کارت موبایل اصلاح شد.
- نقش مالی NTSW حفظ شده است. کارت مانده تعهد بر دانه ثبت سفارش × ارز جمع می‌شود، تکرار یک مانده را حذف می‌کند، ارزهای متفاوت را جدا نگه می‌دارد و در نبود داده/تعارض، عدد ساختگی نشان نمی‌دهد.
- import نوع Any در آداپتور گمرک، کلید تکراری آداپتور مقاومت و رنگ‌های خارج از توکن در شیت تاریخچه اصلاح شد.

## شواهد و اجرای مجدد

اجرای کامل: ۹۴۵ بررسی موفق و یک شکست مربوط به رنگ ثابت شیت تاریخچه. پس از اصلاح رنگ، تمام ۹۳ بررسی مجموعه طراحی دوباره پاس شدند. حاصل تلفیقی: ۹۴۶ بررسی موفق و صفر شکست حل‌نشده؛ بعد از آخرین تغییر رنگ، کل مجموعه از ابتدا تکرار نشده است.

نتیجه نهایی عددی در `PACKAGE_INFO_V29_6_10.json` و لاگ‌های `audit/` ثبت شده است.

- ۹ تست تازه در `tests/test_fullstack_v29_6_10.py`: اجرای واقعی فایل Dashboard و Studio با Streamlit AppTest، محدوده داده/ستون، مرز موجودی، تاریخ مرجع و جمع مالی. ورودی Pipeline و snapshot در دو AppTest مصنوعی و mock شده‌اند؛ شبکه سازمان آزمایش نشده است.
- ۹ بررسی مرورگر Chromium واقعی: جست‌وجوی ردیف ۱۷۰ با ارقام فارسی، ۱۷۵ نتیجه با نمایش ۵ ردیف، دانلود هر دو Excel، کیبورد RTL، عرض موبایل ۳۹۰ و نبود خطای JavaScript. نتایج در `audit/BROWSER_RESULTS.json` و تصاویر desktop/mobile است.
- بازخوانی Excel با openpyxl: هر دو فایل ۱۷۵ ردیف دارند؛ شناسه `999999999999999999` دقیقاً و با نوع متن حفظ شده است (`audit/EXCEL_RESULTS.json`).
- Doctor: صفر خطا، ۱۱ هشدار. شش مسیر شبکه شرکت در این محیط در دسترس نیست؛ تنظیم Store شخصی موجود نیست؛ jdatetime اختیاری نصب نیست؛ سه هشدار به نیاز بازبینی قواعد و موعدهای ثبت‌شده مربوط است. قواعد حقوقی/بخشنامه‌ها در این دیباگ راستی‌آزمایی نشده‌اند.
- تحلیل ایستا: نام تعریف‌نشده یا متغیر استفاده‌شده پیش از تعریف یافت نشد؛ هشدارهای سبک و import بدون استفاده در `audit/STATIC_ANALYSIS.log` حفظ شده‌اند.

برای اجرای مجموعه Python:

```bash
pip install -r requirements-dev.txt
python run_all_tests.py
python -m gsi.doctor
```

رانر، تست‌های جدید را نیز کشف می‌کند و تست‌های قدیمی دارای نقطه ورود script را به همان شکل اجرا می‌کند. اجرای مستقیم pytest روی کل پوشه با ساختار قدیمی بعضی تست‌ها سازگار نیست. تعدادها شامل بررسی‌های رانرهای قدیمی است، نه فقط تعداد تابع pytest.

برای نمونه مرورگر:

```bash
python tools/make_fullstack_qa_sample.py samples/FULLSTACK_QA.html
# Playwright و Chromium باید در محیط QA نصب باشند.
# GSI_PLAYWRIGHT: مسیر ماژول playwright؛ GSI_CHROMIUM: مسیر executable
node tools/check_html_browser.cjs samples/FULLSTACK_QA.html audit
```

برخی تست‌های قدیمی انتظار منسوخ داشتند: موجودی کل به جای موجودی انبار، چند مخاطب به جای مخاطب انتخابی، شناسه‌های DOM حذف‌شده، تعداد تب بدون نمای متریال و شمارش متنی Dispatch. انتظارها با قرارداد جاری هماهنگ شد. fixtureهای فرآیند/FX نیز کلید اتصال مستقل دریافت کردند؛ رفتار محدوده برای پاس‌کردن تست باز نشده است. لاگ قبل از اصلاح تست‌ها نگه داشته شده است.
