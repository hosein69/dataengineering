# AIBL V26.1 — Readability & Criticality Fix

## Executive fixes
- شیت «کارنامه سازمانی» اکنون بحرانی بودن بارنامه را از وضعیت کل BL محاسبه می‌کند؛ اگر یک BL چند متریال داشته باشد، وجود حتی یک `STOCKOUT`/`CRITICAL` کل BL را بحرانی می‌کند و دیگر اولین ردیف BL نتیجه را تعیین نمی‌کند.
- رنگ وضعیت در گزارش‌ها یکدست شد: قرمز = Critical/Stop Line، نارنجی = Becoming Critical، زرد = Watch، سبز = Safe، خاکستری = Inactive/No Data.
- فونت گزارش اکسل به `IRANSans Light` تغییر یافت؛ متن نمودارهای Excel نیز به همین فونت قفل شد.
- چیدمان نمودارهای Excel بازطراحی شد: فاصله بیشتر، نمودارهای بزرگ‌تر و عنوان‌های کوتاه‌تر برای جلوگیری از هم‌افتادگی متن.
- نمودارهای تصویری ایمیل برای جلوگیری از مشکل RTL/رندر فارسی، عنوان‌ها/محورها/Legend را انگلیسی و خوانا می‌کنند؛ خود متن ایمیل از فونت `IRANSans Light` استفاده می‌کند.
- تست‌های Regression برای باگ «کارنامه = صفر»، رنگ وضعیت، فونت ایمیل و تولید سه نمودار ایمیل اضافه شد.
