# GSI V29.3 — Static Shared-Folder Chatbot

این نسخه Knowledge Desk را برای محیط کاملاً آفلاین و بدون سرویس شبکه بازطراحی می‌کند.

## معماری

`Shared Knowledge Folder -> Python Index Build -> Static Bundle -> chatbot.html`

هیچ HTTP server، Docker، AnythingLLM، Vector DB یا اتصال اینترنت برای مصرف کاربران لازم نیست.

## راه‌اندازی از Streamlit

از محیط **دستیار دانش بازرگانی** سه مسیر تعیین می‌شود:

1. پوشه پایگاه دانش سازمانی
2. پوشه آموزش‌های هفتگی
3. پوشه مشترک انتشار Chatbot

با دکمه **ایجاد / به‌روزرسانی چت‌بات آفلاین** این فایل‌ها تولید می‌شوند:

- `chatbot.html` — فایل مستقل و قابل اجرا از Shared Folder
- `knowledge_index.json` — نمای قابل ممیزی index
- `weekly_lessons.json` — آموزش‌های کشف‌شده
- `manifest.json` — آمار ساخت و نسخه

`chatbot.html` index را داخل خودش نیز دارد تا برای کار کردن به `fetch()` روی `file://` وابسته نباشد.

## رفتار گزارش HTML

اگر Chatbot ساخته شده باشد، بخش آموزش در HTML گزارش دارای کادر سؤال است. با زدن «پرسیدن» فایل `chatbot.html` از Shared Folder باز می‌شود و سؤال از قبل در آن قرار می‌گیرد. این طراحی به JavaScript فعال داخل Outlook وابسته نیست؛ لینک عادی «باز کردن دستیار آفلاین» نیز وجود دارد.

## حریم مسیرها

مسیر واقعی فایل‌های منبع در `knowledge_index.json` و `chatbot.html` منتشر نمی‌شود؛ فقط نام/مسیر نسبی منبع نمایش داده می‌شود. با این حال خود لینک بازکردن Chatbot ناگزیر باید مقصد Shared Folder را در `href` داشته باشد. اگر سازمان نمایش UNC را نمی‌خواهد، از DFS Alias یا Drive Mapping سازمانی استفاده شود.

## جست‌وجو

نسخه V29.3 عمداً مولد LLM نیست. جست‌وجوی فارسی در مرورگر با normalization، token ranking، title boost و استخراج جمله‌های مرتبط انجام می‌شود. اگر مدرک کافی پیدا نشود، سیستم پاسخ‌سازی نمی‌کند.

## محدودیت محیط سازمانی

اگر Policy مرورگر/Outlook لینک‌های `file://` یا UNC را مسدود کند، خود بسته سالم است اما مسیر انتشار باید از روش مورد تأیید IT مثل DFS یا mapped drive ارائه شود.
