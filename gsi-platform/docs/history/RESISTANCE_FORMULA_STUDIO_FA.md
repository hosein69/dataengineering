# GSI V28 — Resistance Formula Studio

این build بر اساس تصمیم عملیاتی کاربر تنظیم شده است:

- موجودی پیش‌فرض = موجودی SAPCO + موجودی IKCO + نزد سازنده + در راه + در گمرک.
- مخرج = نیاز روزانه Oracle.
- Oracle دو شیت Sheet1 و SAPCO_IK را روی «شماره فنی» مقایسه می‌کند؛ مقادیر هم‌نام بین شیت‌ها جمع نمی‌شوند.
- DAILY_NEED برابر بزرگ‌ترین مقدار معتبر بین «نیاز روزانه قطعات» و «میانگین نیاز روزانه (عدد)» است؛ اگر فقط یکی موجود باشد همان استفاده می‌شود.
- STOCK_IKCO و STOCK_SAPCO نیز بین شیت‌های Oracle جمع نمی‌شوند؛ برای overlap مقدار معتبر بزرگ‌تر انتخاب می‌شود.
- مقاومت جزءبه‌جزء برای IKCO، SAPCO، نزد سازنده، در راه و گمرک تولید می‌شود.
- تب «🧮 فرمول مقاومت» در Streamlit امکان انتخاب ستون‌های صورت و مخرج را می‌دهد.
- Missing به صورت پیش‌فرض صفر نمی‌شود؛ کاربر می‌تواند حالت lower-bound را انتخاب کند.
- فیلدهای هر Template مستقل قابل انتخاب‌اند؛ از جمله درصد سهم خرید خارج.
- HTML رسمی هر Template فقط یک persona دارد؛ گزارش کارشناس/مدیر/مدیر ارشد به صورت پیش‌فرض در یک فایل ترکیب نمی‌شود.
- لایه HTML/Design همان آخرین Design System/Figma handoff موجود در V28 است (gsi/design + PRODUCT_DESIGN_SYSTEM_V27_FA.md).
