# GSI V29.6.2 — Material HTML Tab/Filter Fix

## مسئله
در V29.6.1 برای همسان‌سازی دید تأمین با HTML، یک جدول مستقل «دید تأمین — متریال محور» خارج از paneهای Report Composer به HTML افزوده شد. این جدول روی همه تب‌ها دیده می‌شد و وارد runtime فیلتر تب (`rows(t)`) نمی‌شد؛ در نتیجه فیلتر، KPI، نمودار و Export آن با تب فعال همگام نبود.

## اصلاح V29.6.2
- جدول سراسری/ثابت متریال از HTML حذف شد.
- `KEY_MATERIAL` به‌عنوان Business Identity در جدول اصلی تب اول حفظ می‌شود (برای سازگاری Templateهای قدیمی که قبل از اضافه شدن این فیلد ذخیره شده‌اند).
- متریال داخل همان جدول استاندارد Composer رندر می‌شود، نه در یک Section جدا.
- برای شناسه‌های پرتعداد (از جمله `KEY_MATERIAL`) به‌جای Select چندصدگزینه‌ای، فیلتر متنی `contains` در Toolbar همان تب ساخته می‌شود.
- فیلترهای متنی و Select هر دو از یک مسیر runtime (`rows(t)`) استفاده می‌کنند؛ بنابراین جدول، KPI، نمودار و Excel Filtered هم‌دامنه‌اند.
- فیلتر هر تب با `data-pane` scoped است و به تب دیگر نشت نمی‌کند.

27 تست مرتبط HTML / Report Builder / Supply Views پاس شد.
